Пример 25. Проверка гипотезы о равенстве средних (t-критерий Стьюдента)

Задача. Две группы студентов учились по разным методикам. Средний балл группы А (25 человек) — 74, группы Б (25 человек) — 79. Есть ли статистически значимое различие?

  1. Гипотезы. H0: средние баллы групп равны; H1: средние различаются. Уровень значимости α = 0,05.
  2. Критерий. Двухвыборочный t-критерий Стьюдента для независимых выборок. Условия: баллы распределены нормально, дисперсии групп равны.
  3. Критическая область — двусторонняя, так как H1 не указывает направление различия.
  4. Вывод. Пусть вычисленное значение t попало в критическую область (p-значение = 0,02 < 0,05). Тогда H0 отвергается: различие значимо.

В R это делается одной командой:

t.test(scores_a, scores_b, var.equal = TRUE)

Возможные ошибки. Если на самом деле методики не различаются, а мы отвергли H0, — это ошибка первого рода (вероятность не больше α = 0,05). Если различие есть, а мы его не обнаружили, — ошибка второго рода (β).

Для классификации используется индикатор ошибки: L = 1, если α(x) ≠ y(x), иначе 0. Если модель ошиблась на 3 объектах из 20, средняя потеря равна 3/20 = 0,15 (доля ошибок).
