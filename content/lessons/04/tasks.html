Задание 1. Сравнительная таблица аналитических систем

Цель: Систематизировать знания о Power Query, Power BI, Pyramid Analytics и компонентах SQL Server.

Порядок выполнения:

  1. Составьте таблицу из четырёх систем.
  2. Для каждой укажите: назначение, основные возможности, достоинства, недостатки.
  3. Добавьте строку «Работа с OLAP-кубами» и заполните её по материалам лекции.
  4. Подберите систему для двух сценариев: студенческий проект без бюджета и крупный банк с собственным SQL Server.

Ожидаемый результат: Заполненная таблица и два обоснованных выбора.

Форма представления: Таблица и два абзаца с обоснованием.

Задание 2. Многомерный куб для таблицы заказов

Цель: Научиться переходить от одномерного набора данных к сводной таблице и кубу.

Порядок выполнения:

  1. Возьмите таблицу Invoices из раздела «Примеры» (дата, страна, город, заказчик, доставщик, товар, количество, сумма).
  2. Сформулируйте вопрос, ответом на который будет вектор (одно измерение).
  3. Сформулируйте вопрос, ответом на который будет сводная таблица (два измерения).
  4. Сформулируйте вопрос для трёхмерного куба.
  5. Укажите, какое максимальное число измерений можно получить из этой таблицы, и объясните почему.

Ожидаемый результат: Три вопроса разной размерности и ответ о максимальном числе измерений.

Форма представления: Нумерованный список с пояснениями.
