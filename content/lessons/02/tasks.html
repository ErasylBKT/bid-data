Задание 1. Применение Big Data в отрасли

Цель: Научиться связывать задачи бизнеса с задачами, решаемыми Big Data.

Порядок выполнения:

  1. Выберите три задачи из списка «Задачи, решаемые Big Data» (например, выявление мошенничества, анализ текучести клиентов, прогноз погоды).
  2. Для каждой задачи укажите отрасль, источники данных и ожидаемый результат анализа.
  3. Для одной из задач опишите все пять этапов анализа данных: гипотеза, сбор, модель, тестирование, использование.

Ожидаемый результат: Описание трёх задач и подробная схема анализа для одной из них.

Форма представления: Таблица «Задача — Отрасль — Источники данных — Результат» и нумерованный список из пяти этапов.

Подсказка

Ориентируйтесь на примеры операторов связи и банков из раздела «Примеры».

Задание 2. Оценка эффективности маркетинга

Цель: Научиться количественно оценивать пользу анализа данных.

Порядок выполнения:

  1. Используя данные примера оператора связи (0,7%, 4%, 11%, 24%), рассчитайте число откликов на 500 000 предложений для каждого уровня.
  2. Вычислите, во сколько раз каждый следующий уровень эффективнее массовой рассылки.
  3. Сделайте вывод, какие данные дали наибольший прирост.

Ожидаемый результат: Четыре значения числа откликов, три коэффициента роста и вывод.

Форма представления: Таблица с расчётами и вывод из 2–3 предложений.
