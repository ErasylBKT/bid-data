Задание 1. Постановка задач машинного обучения

Цель: Научиться формализовать задачу машинного обучения: объекты, ответы, признаки, тип задачи.

Порядок выполнения:

  1. Для каждой задачи укажите множество объектов X, множество ответов Y, тип задачи (бинарная или многоклассовая классификация, регрессия, кластеризация, ассоциативные правила) и вид обучения (с учителем или без): (а) определить, сдаст ли студент экзамен; (б) предсказать температуру на завтра; (в) сгруппировать покупателей без заранее заданных групп; (г) определить жанры фильма (их может быть несколько); (д) найти товары, которые часто покупают вместе.
  2. Для задачи (а) предложите 5 признаков и укажите тип каждого (бинарный, номинальный, количественный).
  3. Для задач (а) и (б) укажите подходящую функцию потерь.

Ожидаемый результат: Таблица из 5 задач, список признаков и функции потерь.

Форма представления: Таблица «Задача — X — Y — Тип — Обучение» и пояснения.

Подсказка

Y = {0, 1}^M соответствует классам, которые могут пересекаться.

2. Сводные таблицы

Создайте сводную таблицу, показывающую средние значения по переменной cyl

(количество цилиндров):

mtcars_summary <- mtcars %>%
