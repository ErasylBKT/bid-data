3. Установка и запуск локальной версии (без интернета)

Пособию не нужна установка в систему: достаточно скопировать папку.

  1. Скопируйте папку с пособием (в которой лежит файл index.html) на жёсткий диск, флешку или сетевой диск компьютерного класса. Например: C:\Учебники\Анализ больших данных\.
  2. Откройте папку и дважды щёлкните файл index.html. Пособие откроется в браузере, установленном по умолчанию.
  3. Если файл открылся в другой программе, щёлкните по нему правой кнопкой мыши → «Открыть с помощью» → выберите браузер.
  4. Для удобства создайте ярлык: щёлкните index.html правой кнопкой → «Отправить» → «Рабочий стол (создать ярлык)» (Windows) или перетащите файл в Dock (macOS).
Важно. Результаты обучаемых сохраняются в браузере того компьютера, на котором открыто пособие. В компьютерном классе каждый студент должен работать на одном и том же компьютере и в одном браузере либо переносить результаты (раздел 7).

Установка с проверкой версии операционной системы не требуется: одна и та же папка работает в Windows, macOS, Linux, Android и iOS.

4. Размещение сетевой версии в интернете

Сетевая версия — это та же папка, размещённая на любом веб-сервере. Программная часть сервера не нужна: подходит любой хостинг статических файлов.

4.1. GitHub Pages (бесплатно)

  1. Зарегистрируйтесь на github.com и войдите в аккаунт.
  2. Нажмите «+» → «New repository». Укажите имя, например big-data-textbook, выберите «Public» и нажмите «Create repository».
  3. На странице репозитория нажмите «uploading an existing file» и перетащите в окно всё содержимое папки пособия (файл index.html и папки assets, data, images, docs). Нажмите «Commit changes».
  4. Откройте «Settings» → «Pages». В разделе «Build and deployment» выберите «Deploy from a branch», ветку main, папку / (root) и нажмите «Save».
  5. Через 1–2 минуты пособие будет доступно по адресу https://ВАШ-ЛОГИН.github.io/big-data-textbook/.

4.2. Сервер университета

Передайте администратору папку пособия и попросите разместить её в любом каталоге веб-сервера (Apache, Nginx, IIS). Дополнительные настройки сервера не нужны.

5. Встраивание в Google Sites

Google Sites не позволяет загружать HTML-сайты, поэтому пособие сначала размещается в интернете (раздел 4), а затем встраивается по адресу.

  1. Откройте свой сайт в редакторе Google Sites.
  2. Справа выберите «Вставить» → «Встроить» → вкладка «По URL».
  3. Вставьте адрес сетевой версии (например, https://ВАШ-ЛОГИН.github.io/big-data-textbook/) и выберите «Вся страница».
  4. Растяните встроенный блок на всю ширину и высоту страницы. Нажмите «Опубликовать».
Во встроенном окне некоторые браузеры (Safari, режим инкогнито) запрещают сохранение данных. Пособие само показывает предупреждение и кнопку «Открыть в новом окне» — в новой вкладке результаты сохраняются. Рекомендуется также разместить на странице Google Sites обычную ссылку на сетевую версию.

6. Проверка работоспособности

  1. Откройте пособие: должна появиться титульная страница с названием «Анализ больших данных» и оглавлением слева (на телефоне — по кнопке ☰).
  2. Нажмите «Режим просмотра» — должен открыться урок 1 с теорией.
  3. Нажмите «?» — должен открыться помощник.
  4. Ответьте на один вопрос урока 1 и обновите страницу: отметка «решён» должна сохраниться.
  5. Удалите тестовый профиль: «Пользователи» → «Удалить профиль».

Если страница пустая — проверьте, что в браузере включён JavaScript и что в папке есть assets и data. Если появляется жёлтое предупреждение о сохранении данных — разрешите сохранение данных сайтов в настройках браузера или откройте пособие в новом окне.

7. Резервное копирование данных

Пособие создаёт данные: профили обучаемых, ответы, результаты тестов и настройки преподавателя. Они хранятся в браузере (localStorage) и удаляются при очистке истории браузера или данных сайтов. Чтобы не потерять их:

  • Обучаемый: «Статистика» → «Выгрузить в JSON» — файл с вашими результатами. Его можно передать преподавателю.
  • Преподаватель: «Пользователи» → «Панель преподавателя» → «Резервная копия (JSON)» — все профили и результаты на этом компьютере. Восстановление: там же «Загрузить копию». Так же можно объединить результаты с разных компьютеров.
  • Рекомендуется делать резервную копию в конце каждого занятия и хранить файлы на сетевом диске или в облаке.
  • Для отчётности используйте «Выгрузить в CSV (Excel)».

8. Обновление содержания

Учебный материал хранится отдельно от программы, поэтому его можно менять без изменения исходного кода (СТ РК 34.017-2005, §5). Это делает автор курса на компьютере с Python 3:

  1. Отредактируйте файлы в папке проекта authored/: lessons/NN.json — примеры, задания, вопросы, тесты и термины урока NN; course/meta.json — выходные сведения; reference/reference.html — справочник; overrides/ и patches.json — исправления теории.
  2. Проверьте изменения: python3 tools/validate_authored.py .
  3. Соберите пособие: python3 -I tools/build_content.py ., затем python3 -I tools/build_site.py .
  4. Скопируйте обновлённую папку site/ на флешки и/или загрузите на хостинг. Результаты обучаемых при этом сохраняются.

9. Удаление

Удалите папку пособия. Чтобы удалить сохранённые результаты, очистите данные сайта в настройках браузера (для локальной версии — данные для «файлов»). Перед этим сделайте резервную копию (раздел 7), если результаты нужны.
