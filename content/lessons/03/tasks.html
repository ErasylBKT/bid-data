Задание 1. Проектирование ETL-процесса

Цель: Научиться описывать этапы извлечения, преобразования и загрузки данных.

Порядок выполнения:

  1. Придумайте 3 источника с разной структурой (например, журнал посещаемости в Excel, выгрузка из LMS в CSV, анкета в Google Forms).
  2. Опишите для каждого источника: формат, ключевые поля, возможные ошибки (дубликаты, пропуски, разные форматы дат).
  3. Определите целевую структуру таблицы хранилища.
  4. Распишите правила преобразования для каждого источника.
  5. Укажите, что произойдёт при появлении четвёртого источника.

Ожидаемый результат: Схема ETL из трёх компонентов (источник, промежуточная область, получатель) и правила преобразования.

Форма представления: Схема (рисунок или таблица) и список правил.

Подсказка

Вспомните пример с N магазинами и K дистрибьюторами из теории.

Задание 2. Многомерный анализ

Цель: Освоить операции OLAP на учебном кубе.

Порядок выполнения:

  1. Задайте куб с измерениями «Время», «Факультет», «Курс» и показателем «Средний балл».
  2. Для каждой операции (срез, детализация, свёртка, вращение, сравнение во времени) сформулируйте один вопрос, на который она отвечает.
  3. Укажите иерархию уровней обобщения для измерения «Время».

Ожидаемый результат: Пять вопросов с указанием операции OLAP и иерархия измерения.

Форма представления: Таблица «Операция — Вопрос — Что меняется в кубе».
