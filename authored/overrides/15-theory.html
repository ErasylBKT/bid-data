Кластеризация

Кластеризация — это обучение без учителя. Это задача разделить множество объектов на различные группы, которые называются кластерами.

Цели кластеризации:

  • упрощение дальнейшей обработки данных — разбиение пространства объектов на группы схожих объектов, чтобы работать с каждой группой отдельно (классификация, регрессия, прогнозирование);
  • сокращение объёма хранимых данных — оставление по одному представителю от каждого кластера (сжатие данных);
  • выделение нетипичных объектов, которые не подходят ни к одному кластеру (одноклассовая классификация);
  • построение иерархии множества объектов — таксономия.

Постановка задачи. Даны X — пространство объектов, Xn = {xi}i=1n — обучающая выборка и ρ: X × X → [0, ∞) — функция расстояния между объектами. Требуется найти множество кластеров Y и алгоритм кластеризации α: X → Y такие, что каждый кластер состоит из близких объектов, а объекты разных кластеров существенно различаются.

Задача кластеризации некорректна (неоднозначна), потому что:

  • чёткой постановки задачи не существует;
  • существует много критериев качества кластеризации;
  • существует много эвристических методов деления на кластеры;
  • число кластеров, как правило, заранее неизвестно;
  • результат зависит от выбора метрики ρ, который субъективен.

Типы кластерных структур

1. Кластеры, расстояния внутри которых меньше, чем между ними.

2. Ленточные кластеры.

3. Кластеры с центром.

4. Соединённые кластеры.

5. Кластеры, наложенные на фон разреженных объектов.

6. Перекрывающиеся кластеры.

Каждый метод кластеризации имеет свои ограничения и выделяет кластеры лишь некоторых типов. Понятие «тип кластерной структуры» зависит от метода и не имеет формального определения. Самые известные методы кластеризации — метод k-средних, метод c-средних, сеть Кохонена и другие.

Алгоритм k-means (k-средних)

  1. Инициализировать центры кластеров μ1, …, μk случайным образом.
  2. Вычислить расстояния ρ(xi, μk) от каждого объекта до каждого центра.
  3. Отнести каждый объект к ближайшему центру. Так формируются кластеры Xk.
  4. Вычислить новые центры кластеров как среднее значение всех точек кластера:

    μk = (1 / sk) · Σx ∈ Xk x,   где sk — количество точек в кластере k.

  5. Если центры изменились (сдвинулись), повторить с шага 2; иначе завершить работу.

Функционал качества кластеризации:

Q = c · d0 / d1 → min,

где c — количество кластеров, d0 — среднее внутрикластерное расстояние, d1 — среднее межкластерное расстояние. Задача обучения — минимизация функционала качества.

Недостатки k-means:

  • нет гарантии достижения глобального минимума — только одного из локальных;
  • результат зависит от выбора начальных центров, и их оптимальный выбор неизвестен;
  • число кластеров нужно знать заранее;
  • кластерный анализ не всегда даёт удовлетворительные результаты;
  • необходим эвристический подбор параметров алгоритма, в частности начальных значений центров.

Алгоритм c-means (нечёткий метод c-средних)

Для заданного множества входных векторов xk и N выделяемых кластеров cj предполагается, что любой вектор xk принадлежит любому кластеру cj со степенью принадлежности µjk ∈ [0, 1], где j — номер кластера, k — номер входного вектора.

  1. Инициализация: задать количество кластеров N (2 < N < K), параметр q (обычно q = 1,5) и матрицу принадлежности U(0) = (µjk)(0) с учётом начальных центров кластеров cj.
  2. Уточнение центров: на t-м шаге по известной матрице U вычислить центры cj(t).
  3. Корректировка принадлежности: по известным центрам cj(t) вычислить µjk(t).
  4. Остановка: если матрица U не меняется — завершить, иначе перейти к шагу 2.

В k-means неясно, как поступать с объектом, который в равной степени близок к нескольким кластерам или не близок ни к одному. Алгоритм c-means решает эту проблему: он вычисляет степень принадлежности объекта к каждому кластеру, которая определяется расстоянием объекта до центров кластеров. Кластеры здесь являются нечёткими множествами с нечёткими границами. Цель алгоритма — минимизация суммы взвешенных расстояний.

Поиск ассоциативных правил

Обозначения:

  • X — пространство объектов;
  • F = {f1, …, fk}, fj: X → {0, 1} — бинарные признаки;
  • Xn = {x1, …, xn} ⊂ X — обучающая выборка.

Каждому подмножеству φ ⊆ F соответствует конъюнкция φ(x) = ∧f ∈ φ f(x), x ∈ X. Если φ(x) = 1, то «признаки из φ совместно встречаются у x».

Частота встречаемости (поддержка) набора φ в выборке Xn:

v(φ) = (1/n) · Σi=1n φ(xi)

Если v(φ) ≥ δ, то набор φ называется частым. Параметр δ — минимальная поддержка (MinSupp).

Ассоциативное правило φ → y — это пара непересекающихся наборов φ, y ⊆ F таких, что:

  1. наборы φ и y совместно часто встречаются: v(φ ∪ y) ≥ δ;
  2. если встречается φ, то часто встречается и y:

    v(y | φ) ≡ v(φ ∪ y) / v(φ) ≥ ϰ

Величина v(y | φ) — значимость правила; параметр ϰ — минимальная значимость (MinConf).

Свойство антимонотонности

Задача — найти наборы элементов, встречающиеся наиболее часто. Простейший подход — перебор всех возможных наборов, но он слишком трудоёмок. Сократить пространство поиска позволяет свойство антимонотонности: с ростом набора его поддержка уменьшается или остаётся прежней.

Для любых ψ, φ ⊆ F: из φ ⊂ ψ следует v(φ) ≥ v(ψ).

Алгоритм Apriori

Вход: обучающая выборка Xn; минимальная поддержка δ; минимальная значимость ϰ.
Выход: R = {(φ, y)} — список ассоциативных правил.

  1. Множество всех частых исходных признаков: G1 := { f ∈ F | v(f) ≥ δ };
  2. для всех j = 2, …, n:
  3.    множество всех частых наборов мощности j:
       Gj := { φ ∪ {f} | φ ∈ Gj−1, f ∈ G1 \ φ, v(φ ∪ {f}) ≥ δ };
  4.    если Gj = ∅, то
  5.       выход из цикла по j;
  6. R := ∅;
  7. для всех ψ ∈ Gj, j = 2, …, n:
  8.    AssocRules(R, ψ, ∅).

Процедура AssocRules(R, φ, y) — рекурсивно строит правила из частого набора:

  1. для всех f ∈ φ таких, что idf > maxg ∈ y idg (чтобы избежать повторов; idf — порядковый номер признака f в F = {f1, …, fn}):
  2.    φ′ := φ \ {f};  y′ := y ∪ {f};
  3.    если v(y′ | φ′) ≥ ϰ, то
  4.       добавить ассоциативное правило (φ′, y′) в список R;
  5.       если |φ′| > 1, то
  6.          AssocRules(R, φ′, y′).
