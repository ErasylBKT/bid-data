АНАЛИЗ БОЛЬШИХ ДАННЫХ
Электронное учебное пособие (СТ РК 34.017-2005)
ПРОЧТИ МЕНЯ
==================================================================

КАК ЗАПУСТИТЬ
1. Скопируйте эту папку целиком на компьютер или флешку.
2. Откройте файл index.html двойным щелчком - пособие откроется в браузере.
   Интернет не нужен. Установка не нужна.
3. Нажмите "Начать обучение" и зарегистрируйтесь.
4. Помощь внутри пособия - кнопка "?" в правом верхнем углу.

ТРЕБОВАНИЯ
- Браузер Chrome, Firefox, Edge, Safari или Яндекс Браузер последних версий,
  включённый JavaScript, разрешённое сохранение данных сайтов.
- Windows 10+, macOS 12+, Linux, Android 9+ или iOS 15+.
- 50 МБ на диске. Звуковая система не нужна.
- Для лабораторных работ: R 4.x и RStudio.

ВАЖНО
- Результаты сохраняются в браузере этого компьютера. Очистка истории
  браузера удаляет результаты. Делайте резервные копии:
  "Статистика" -> "Выгрузить в JSON" (обучаемый) или
  "Пользователи" -> "Панель преподавателя" -> "Резервная копия" (преподаватель).
- Если пособие встроено в сайт (Google Sites) и появилось жёлтое
  предупреждение, нажмите "Открыть в новом окне".

ДОКУМЕНТАЦИЯ (папка docs/)
- docs/install.html       - руководство по установке и запуску
- docs/user-guide.html    - руководство пользователя
- docs/content-guide.html - руководство-содержание, список внешних ссылок

СОСТАВ
index.html - главный файл; assets/ - программа; data/ - содержание курса;
images/ - рисунки; docs/ - документация.

КОНТАКТЫ
Сведения об авторах, издателе и разработчике (адрес, e-mail, телефон) -
на титульной странице пособия ("Выходные сведения").

ҮЛКЕН ДЕРЕКТЕРДІ ТАЛДАУ
Электрондық оқу құралы
МЕНІ ОҚЫ
==================================================================

ҚАЛАЙ ІСКЕ ҚОСУ КЕРЕК
1. Осы папканы толығымен компьютерге немесе флешкаға көшіріңіз.
2. index.html файлын екі рет басыңыз - құрал браузерде ашылады.
   Интернет те, орнату да қажет емес.
3. "Оқуды бастау" батырмасын басып, тіркеліңіз.
4. Құрал ішіндегі көмек - жоғарғы оң жақтағы "?" батырмасы.
   Интерфейс тілін KZ / RU батырмасымен ауыстыруға болады.

МАҢЫЗДЫ
- Нәтижелер осы компьютердегі браузерде сақталады. Браузер тарихын
  тазалау нәтижелерді жояды. Сақтық көшірме жасаңыз:
  "Статистика" -> "JSON түрінде жүктеу".
- Құрал сайтқа (Google Sites) ендірілсе және сары ескерту шықса,
  "Жаңа терезеде ашу" батырмасын басыңыз.

ҚҰЖАТТАМА: docs/ папкасы (орыс тілінде).
