Пример 29. Одна итерация k-means вручную

Данные (одномерные, например, время на сайте в минутах): 2, 3, 4, 10, 11, 12. Число кластеров k = 2.

  1. Инициализация: случайно выбираем центры μ1 = 2, μ2 = 4.
  2. Расстояния и распределение по кластерам: точка 2 → μ1 (0 против 2); 3 → μ1 (1 против 1, при равенстве берём первый); 4, 10, 11, 12 → μ2. Кластеры: {2, 3} и {4, 10, 11, 12}.
  3. Новые центры как средние: μ1 = 2,5; μ2 = (4 + 10 + 11 + 12) / 4 = 9,25.
  4. Центры сдвинулись — повторяем. Точка 4: |4 − 2,5| = 1,5 против |4 − 9,25| = 5,25 → переходит в первый кластер. Кластеры: {2, 3, 4} и {10, 11, 12}; центры 3 и 11.
  5. Следующая итерация не меняет кластеры — алгоритм остановлен.

Замечание. При других начальных центрах результат мог оказаться иным: k-means находит лишь локальный минимум, и число кластеров нужно знать заранее.

x <- c(2, 3, 4, 10, 11, 12)
kmeans(x, centers = c(2, 4))

Пример 30. Поиск ассоциативных правил: поддержка и значимость

Транзакции (n = 6): {хлеб, молоко}, {хлеб, масло}, {хлеб, молоко, масло}, {молоко, масло}, {хлеб, молоко}, {хлеб, молоко, масло}. Минимальная поддержка δ = 0,5; минимальная значимость ϰ = 0,7.

Шаг 1. Частые одиночные признаки (G1): v(хлеб) = 5/6; v(молоко) = 5/6; v(масло) = 4/6 — все ≥ 0,5.

Шаг 2. Частые пары (G2): v(хлеб, молоко) = 4/6 ≈ 0,67 ✓; v(хлеб, масло) = 3/6 = 0,5 ✓; v(молоко, масло) = 3/6 = 0,5 ✓.

Шаг 3. Тройка: v(хлеб, молоко, масло) = 2/6 ≈ 0,33 < 0,5 — не частая. По свойству антимонотонности большие наборы проверять не нужно.

Шаг 4. Правила из пар, значимость v(y | φ) = v(φ ∪ y) / v(φ):

  • хлеб → молоко: (4/6) / (5/6) = 0,8 ≥ 0,7 ✓
  • молоко → хлеб: 0,8 ✓
  • масло → хлеб: (3/6) / (4/6) = 0,75 ✓
  • хлеб → масло: (3/6) / (5/6) = 0,6 ✗

Итог: найдено правило «кто покупает хлеб, в 80% случаев покупает и молоко».
