# Түпнұсқа сайттың көшірмесі

Дереккөз: https://sites.google.com/view/analyze-big-data (көшірілген күні: 2026-11-21)

| Папка / файл | Ішінде |
|---|---|
| `raw/` | Әр беттің түпнұсқа HTML-і (34 бет), өзгеріссіз |
| `html/` | Тек оқу мазмұны, тазартылған HTML (тақырыптар, тізімдер, қалың/курсив, суреттер) |
| `pages/` | Сол мазмұн Markdown форматында — оқуға және өңдеуге ыңғайлы |
| `images/` | Барлық 22 сурет (жергілікті көшірме) |
| `manifest.json` | Беттер тізімі: атауы, таңба саны, сурет саны; суреттердің түпнұсқа сілтемелері |

## Беттер

- `home`, `lectures-index`, `practice-index` — мазмұн тізімдері
- `lecture-01` … `lecture-15` — дәрістер (теория)
- `practice-01` … `practice-15` — практикалық сабақтар
- `labs` — 5 зертханалық жұмыс (RStudio / R)

## Түпнұсқадағы байқалған кемшіліктер (жаңа сайтта түзетіледі)

- Басты беттегі тізімде Лекция 4 жоқ.
- Лекция 5, 6, 7, 13, 14, 15 беттерінде тақырып атауы жоқ (тек «Лекция N»).
- `labs` бетінде R коды ChatGPT-ден көшірілген түрде («R / Копировать код» жазбаларымен), код блоктары бұзылған.
- Суреттерге жазылған қолтаңбалар әр жерде әртүрлі немесе жоқ.
