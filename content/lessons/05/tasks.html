Задание 1. Проектирование задачи MapReduce

Цель: Научиться формулировать задачу в виде функций Map и Reduce.

Порядок выполнения:

  1. Дан журнал веб-сервера, каждая строка которого имеет вид: «дата IP-адрес страница».
  2. Опишите функцию Map для подсчёта числа посещений каждой страницы: что является ключом, что — значением.
  3. Опишите функцию Reduce.
  4. Выполните вручную Map и Reduce для 6 придуманных строк журнала, распределив их между двумя узлами.
  5. Измените решение так, чтобы подсчитывать число посещений по дням.

Ожидаемый результат: Описание функций Map и Reduce, промежуточные пары ключ–значение и итоговый результат для двух вариантов задачи.

Форма представления: Таблицы «Вход — Выход Map», «Ключ — Список значений», «Результат Reduce».

Подсказка

Сравните с примером подсчёта слов: ключом становится то, по чему группируем.

Задание 2. Расчёт хранения в HDFS

Цель: Понять блочную организацию и репликацию HDFS.

Порядок выполнения:

  1. Рассчитайте число блоков и занимаемое место для файлов 200 МБ, 5 ГБ и 1 ТБ при размере блока 64 МБ и репликации 3.
  2. Повторите расчёт для размера блока 128 МБ.
  3. Объясните, почему HDFS неэффективна для хранения миллионов маленьких файлов по 10 КБ (подумайте о метаданных на Name Node).

Ожидаемый результат: Таблица расчётов и объяснение (3–4 предложения).

Форма представления: Таблица «Файл — Блоков (64 МБ) — Блоков (128 МБ) — Место в кластере» и текст.
