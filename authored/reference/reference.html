Порядок выполнения лабораторных работ

  1. Установите R (cran.r-project.org) и RStudio (posit.co).
  2. Установите пакеты один раз: install.packages(c("dplyr", "ggplot2", "stringr", "forecast")).
  3. Для каждой работы создайте отдельный скрипт (File → New File → R Script) и сохраните его с расширением .R.
  4. В отчёт включите: цель, код, результаты (вывод консоли и графики), выводы.
